# NTLS2000 Kodi DEV Repository

Test distribution of **Arctic Fuse 3 DEV (Original)** based on Jurialmunkey's Arctic Fuse 3 v3.4.2.

## Published now

| Kodi add-on | ID | Version |
|---|---|---|
| Repository installer | `repository.ntls2000.kodi.dev` | `0.1.0` |
| Arctic Fuse 3 DEV (original source baseline) | `skin.arctic.fuse.3.dev` | `3.4.2.1` |

- Baseline source: `omega` commit `1f0b8fd67fa73738ea7f6fe1ff6dd8e3859192fb`, Arctic Fuse 3 **v3.4.2**.
- Unchanged upstream visuals, widgets and dependencies. To allow **side-by-side installation**, packaging updates the skin ID, name, version and in-skin references to the new ID. No feature patches.
- Automatic package build: `.github/workflows/publish-baseline.yml`; packaging ZIP was generated by GitHub Actions and validated for ZIP integrity.
- Size: approximately 62.4 MB; complete addon payload including `1080i`, `media`, `extras`, `fonts` and `shortcuts`.

## Install from Kodi (recommended)

1. Install `repository.ntls2000.kodi.dev-0.1.0.zip` from **Add-ons > Install from zip file**.
2. Open **Add-ons > Install from repository > NTLS2000 - Kodi DEV Repository**.
3. Select **Look and feel / Skins > Arctic Fuse 3 DEV (Original)** (menu wording may vary).
4. Install compatible dependencies through their original trusted repositories.
5. Enable this skin from **Interface > Skin** after verifying the installed dependencies.

The existing `skin.arctic.fuse.3` add-on is not replaced. You can switch back to the official skin in Kodi's interface settings.

## Known dependency fix: Arctic Splash 1.0.6 (Kodi 22)

Arctic Fuse 3 DEV 3.4.2.1 requires `resource.images.arctic.splash >= 1.0.6`.
As verified on 2026-10-21, the upstream `repository.jurialmunkey` catalog's `repo/zips` still indexes **v1.0.0**. The upstream source `jurialmunkey/resource.images.arctic.splash` is **v1.0.6**. Kodi cannot satisfy the minimum version via the upstream catalog alone.

**Install the complete original-resource v1.0.6 package manually once:**

- [Arctic Splash v1.0.6 Kodi ZIP](https://github.com/ntls2000/skin.arctic.fuse.3/releases/download/arctic-splash-1.0.6-dependency/resource.images.arctic.splash-1.0.6.zip)
- [SHA256 checksum](https://github.com/ntls2000/skin.arctic.fuse.3/releases/download/arctic-splash-1.0.6-dependency/SHA256SUMS-arctic-splash.txt)
- [Source revision](https://github.com/ntls2000/skin.arctic.fuse.3/releases/download/arctic-splash-1.0.6-dependency/arctic-splash-source-commit.txt)
- Build workflow: `.github/workflows/package-arctic-splash.yml`.

In Kodi: **Add-ons > Install from zip file**; select `resource.images.arctic.splash-1.0.6.zip`, then retry installing **Arctic Fuse 3 DEV (Original)**. This ZIP contains all 754 addon files (manifest plus original `resources/`), with ZIP integrity verified in GitHub Actions. No artwork files or version requirements were removed.

Because the complete ZIP is approximately 124.6 MB (larger than GitHub's normal 100 MiB per-blob limit), it is hosted as a GitHub **Release asset** rather than an ordinary file in `kodi-repository/`. It is **not automatically installable through this repository's Kodi catalog** yet. Do not confuse a published release asset with a registered Kodi repository add-on. This procedure is a one-time manual dependency installation; the skin itself remains installable from the NTLS2000 repository.

## Dependencies and compatibility

The original skin dependencies are preserved:
- `xbmc.gui >= 5.17.0` (Kodi interface component)
- `script.skinvariables >= 2.2.9`
- `script.texturemaker >= 0.2.9`
- `plugin.video.themoviedb.helper >= 6.17.9`
- `resource.images.weathericons.white >= 0.0.1`
- `resource.images.arctic.splash >= 1.0.6`
- `resource.images.studios.coloured >= 0.0.1`
- `resource.font.robotocjksc >= 0.0.3`

Third-party addons including Emby for Kodi Next Gen and Arctic Stream are **not bundled**. Their installed versions and compatibility must be checked on the actual Kodi devices. This first build has been validated in CI for packaging and metadata, **not functionally tested in Kodi 22**.
